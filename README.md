# Union Add

Modern advertising and digital marketing agency website built with Next.js.

Union Add is a full-service advertising agency providing branding, digital marketing, SEO, web development, media planning, creative design, video production, outdoor advertising, and other marketing solutions.

## 🚀 Features

- Modern and responsive design
- Next.js App Router
- TypeScript
- Tailwind CSS
- Light and dark mode
- Responsive navigation
- Advertising & digital marketing services
- Portfolio showcase with category filtering
- Portfolio search
- Get a Quote form
- MongoDB database integration
- Resend E-Mail Integration
- AI-powered website assistant
- WhatsApp integration
- Contact page
- Responsive UI for mobile, tablet, and desktop
- SEO-friendly pages
- Metadata and Open Graph support
- Canonical URLs
- JSON-LD structured data
- Breadcrumb structured data
- Optimized images with Next/Image
- Custom loading, error, and 404 pages

## 🛠️ Tech Stack
